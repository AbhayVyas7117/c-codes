# C Programs

Practice programs in C (folder C_Programs), sorted by topic. Every file is a complete program that compiles and runs on its own.

| Folder | Topics |
|---|---|
| `Basics/` | I/O, arithmetic, if-else, switch, bills, BMI, age calculator, date validity |
| `Loops_and_Numbers/` | while/for/do-while, series, digits, prime, Armstrong, palindrome, menus |
| `Patterns/` | star, number and binary patterns |
| `Arrays/` | traversal, search, sort, insert, delete, merge |
| `Strings/` | string handling and `string.h` functions |

## Compile and run

```bash
gcc Basics/01_work_hours_salary.c -o prog -lm
./prog
```

`-lm` is only needed for programs that use `pow()`.
